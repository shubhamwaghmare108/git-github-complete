# Beginner Labs

### Lab 01 — First repository
Initialize a repository, create a file, stage it and commit it.

### Lab 02 — Three snapshots
Create three commits and inspect them with `git log --oneline` and `git show`.

### Lab 03 — Branch basics
Create a feature branch, commit a change and merge it.

### Lab 04 — Remote
Connect a remote, push a branch and inspect remote-tracking branches.
