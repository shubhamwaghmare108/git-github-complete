# 17 — Real-World Workflows

## Solo workflow
`main → feature branch → local tests → push → PR/checks → merge`

## Team workflow
`issue → feature branch → commits → PR → review → CI → merge → release`

## Hotfix
`release/main → hotfix branch → test → PR → merge → tag/release`

## Keep history useful
Prefer small logical commits, descriptive messages, and focused pull requests.
