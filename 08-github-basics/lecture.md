# GitHub Basics — Full Lecture

Git is the version-control system; GitHub is a platform around Git repositories with collaboration, review, automation and project-management features.

Learn:
- repositories and visibility
- default branch
- branches and forks
- collaborators and permissions
- repository settings
- releases
- Discussions and Projects

### Exercise
Create a repository, add a README, create a feature branch, push it, and inspect the branch in the GitHub UI.
