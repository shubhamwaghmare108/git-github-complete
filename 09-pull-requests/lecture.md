# Pull Requests — Full Lecture

A pull request proposes a branch's changes for integration into a target branch.

### Professional PR checklist
- Explain the problem.
- Describe the solution.
- Link related issues.
- Keep the diff focused.
- Include testing evidence.
- Call out migrations or risks.
- Request appropriate reviewers.

### Conflict exercise
Create conflicting changes in two branches, push both, open a PR, update the branch locally, resolve the conflict and push the resolution.
