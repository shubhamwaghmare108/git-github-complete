# Git + GitHub Complete Course

A practical, teaching-ready curriculum covering Git from fundamentals through GitHub collaboration, CI/CD, security, CLI/API, and disaster recovery.

## Learning path

1. Git basics
2. Git internals and history
3. Undo and recovery
4. Branching, merging, rebasing and cherry-pick
5. Remote Git
6. GitHub repositories and collaboration
7. Pull requests and code review
8. Issues and Projects
9. GitHub Actions
10. Security
11. GitHub Pages
12. GitHub CLI and API
13. Real-world workflows
14. Disaster recovery

## Labs

See `labs/` for beginner, intermediate, advanced and interview exercises.

## Projects

See `projects/` for realistic solo, team and CI/CD workflows.

## Goal

Use this repository as a complete classroom reference and hands-on lab for Git and GitHub.
