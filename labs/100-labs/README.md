# 100+ Git & GitHub Hands-On Labs

A progressive lab sequence for classroom practice. Each lab includes objective, scenario, commands, expected result, task, challenge, solution, and an interview question.

## Levels
- 001-025 Beginner: local Git fundamentals
- 026-050 Intermediate: history, branching, remotes, recovery
- 051-075 GitHub: PRs, issues, review, Actions, security
- 076-100 Advanced: collaboration, automation, API, release and recovery
- 101-110 Capstone: real-world workflows

Complete labs in order when teaching from scratch; instructors may skip labs based on learner level.
