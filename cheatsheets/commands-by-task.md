# Commands by Task

## Start
`git init` · `git clone`

## Inspect
`git status` · `git diff` · `git log` · `git show`

## Stage
`git add` · `git restore --staged`

## Commit
`git commit`

## Branch
`git switch` · `git branch`

## Integrate
`git merge` · `git rebase` · `git cherry-pick`

## Undo
`git restore` · `git reset` · `git revert`

## Recover
`git reflog` · `git fsck`

## Remote
`git fetch` · `git pull` · `git push`

## GitHub
`gh issue` · `gh pr` · `gh run` · `gh api`
