# 09 — Pull Requests and Code Review

A pull request proposes changes from one branch into another.

## Workflow
1. Create feature branch.
2. Make focused commits.
3. Push branch.
4. Open PR.
5. Request review.
6. Respond to comments.
7. Run checks.
8. Merge using the repository policy.
9. Delete branch.

Practice reviewing a deliberately flawed PR and documenting actionable comments.
