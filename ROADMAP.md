# Roadmap

## Beginner
- Working tree, staging area, commits
- status, diff, log, show
- branches and basic merge
- remotes and push/pull

## Intermediate
- reset, restore, revert, reflog
- merge conflicts
- rebase and interactive rebase
- cherry-pick, tags and release flow
- GitHub pull requests and code review

## Advanced
- Git internals and object model
- recovery and disaster scenarios
- GitHub Actions and CI/CD
- security, secrets and branch protection
- GitHub CLI and REST API
- team workflows

## Teaching path
Run the labs after each module, then complete the projects.
