# 03 — History and Inspection

```bash
git log
git log --oneline
git log --graph --decorate --all
git show <commit>
git show --stat <commit>
git diff HEAD~1 HEAD
git reflog
```

Learn to answer: what changed, when, by whom, and which commit introduced a change.

Advanced tools include `git blame`, `git bisect`, path-limited log searches and commit-range notation.
