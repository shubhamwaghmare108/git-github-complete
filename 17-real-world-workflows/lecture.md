# Real-World Git + GitHub Workflows

## Solo
`main → feature → test → push → PR → CI → merge`

## Team
`issue → branch → commits → PR → review → CI → merge → release`

## Hotfix
`release/main → hotfix → test → PR → merge → tag`

## Release discipline
Use version tags, release notes and reproducible builds. Keep commits small enough that reviewers can understand the intent.
